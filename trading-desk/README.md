# Farhang Trading Desk

میز معاملات هوش مصنوعی با ۶ ایجنت، به‌صورت PWA فارسی برای موبایل. بازارها: کریپتو، طلا و فارکس.

| # | ایجنت | کجا اجرا می‌شود |
|---|-------|-----------------|
| 1 | اسکنر بازار: روند، شکست سقف/کف، جهش حجم، ورود پول | روی گوشی |
| 2 | تحلیلگر بنیادی: اخبار با جستجوی وب | Claude |
| 3 | تحلیلگر خوش‌بین | Claude |
| 4 | تحلیلگر بدبین | Claude |
| — | «مغز مشترک»: جمع‌بندی و برنامه معامله (JSON) | Claude |
| 5 | مدیر ریسک: R:R، اهرم، افت سرمایه، حجم پوزیشن | روی گوشی (قوانین قطعی) |
| 6 | بک‌تستر و بهینه‌ساز | روی گوشی |

## نصب روی موبایل
1. صفحه را در مرورگر باز کن (مثلاً از طریق GitHub Pages).
2. iPhone در Safari: دکمه Share ← Add to Home Screen. Android در Chrome: منو ← Install app.
3. تب «تنظیمات» ← کلید API Claude را وارد کن (فقط در حافظه همان گوشی ذخیره می‌شود) ← «تست اتصال».

## داده‌ها
- کریپتو: داده عمومی Binance، با CryptoCompare به‌عنوان جایگزین.
- طلا: PAXGUSDT، توکنی با پشتوانه طلا که تقریباً هم‌قیمت XAU/USD است.
- فارکس: نرخ مرجع روزانه ECB از Frankfurter (فقط کلوز روزانه، بدون حجم).

> این ابزار کمک تحلیلی است، نه توصیه مالی. API شرکت Anthropic و Binance از داخل ایران مسدودند و VPN لازم است.
